# 设置与主题

EverLink 的设置集中在 **我的 → 设置**，另有独立的 **主题** 页面。

## 协议配置

- 列出全部已注册协议（Modbus TCP / MQTT / WebSocket / HTTP / OPC UA）。
- 通过开关启用或停用某个协议。
- **停用后**：该协议不会出现在「添加设备」与首页筛选中，列表更清爽。

## 检查更新

见 [安装与更新](./install) 的「应用内检查更新」一节。

- 选择更新来源：**GitHub** 或 **Gitee**；
- 填写仓库坐标 `owner/repo`；
- 点击 **检查更新**，发现新版本可一键下载安装。

## 主题

在 **我的 → 主题** 中切换外观：

| 选项 | 效果 |
| --- | --- |
| 跟随系统 | 根据系统浅色 / 深色模式自动切换 |
| 浅色 | 始终使用浅色主题 |
| 深色 | 始终使用深色主题 |

切换即时生效。应用以 **teal（青绿色）** 为主色，整体风格清新、低饱和。

## 关于

**我的 → 关于** 展示软件简介与版本信息（版本号、构建号），底部标注版权与用途说明。
