# 协议调试

EverLink 内置五种工业 / 物联网常用协议的调试器，统一通过 **设备** 页的卡片管理。各协议在「添加设备」时选择，调试页提供各自的连接与读写界面。

## 支持的协议

| 协议 | 用途 | 典型端口 |
| --- | --- | --- |
| Modbus TCP | 工业 PLC / 仪表的线圈与寄存器读写 | 502 |
| MQTT | 物联网消息的发布（Publish）与订阅（Subscribe） | 1883 / 8883 |
| OPC UA | 工业设备地址空间浏览与变量读写 | 4840 |
| WebSocket | 与服务端的全双工长连接，收发消息 | 80 / 443 |
| HTTP | REST / HTTP 端点请求调试 | 80 / 443 / 8080 |

> 协议在 **我的 → 设置 → 协议配置** 中可单独启用 / 停用。停用后，该协议不会出现在「添加设备」与首页筛选中。

## 通用流程

1. 在 **设备** 页添加设备，选择协议并填写地址。
2. 点击卡片进入调试页，按需填写更详细的连接参数。
3. 点击连接（或在设备卡片上直接连接）。
4. 在调试页进行读写 / 收发，必要时保存为常用操作。
5. 所有连接与操作都会记录到 **历史** 页。

## Modbus TCP

面向工业控制器与仪表的寄存器调试：

- 读取 / 写入 **线圈（Coil）** 与 **保持寄存器（Holding Register）** 等数据区。
- 通过 `主机 IP + 端口（默认 502）+ 从站地址（Unit ID）` 定位设备。
- **数据类型解析**：支持 INT16 / UINT16 / INT32 / UINT32 / FLOAT32 / BCD 等多种数据类型。
- **字节序 / 字交换切换**：适配不同设备的寄存器字节排列方式。
- **定时轮询**：可设置自动轮询间隔，持续读取寄存器数据。
- **原始 Hex 报文查看**：查看底层 Modbus 请求 / 响应报文。
- **日志导出**：将调试日志导出供离线分析。
- 适用于 PLC、温湿度变送器、电表等 Modbus 从站。

## MQTT

物联网消息调试：

- 支持 **MQTT 3.1.1 / 5.0** 协议版本。
- **TLS / SSL** 加密连接，支持用户名 / 密码与证书认证。
- **多主题订阅**：支持 `#` / `+` 通配符，同时订阅多个主题。
- **JSON 格式化高亮**：自动识别并格式化 JSON 消息 payload。
- **消息历史与发布模板**：保留消息记录，可将常用发布内容保存为模板。
- 常用于传感器上报、设备控制指令下发。

## OPC UA

工业设备地址空间调试：

- **Endpoint 发现**：自动发现局域网内的 OPC UA 服务端 Endpoint。
- **安全策略协商**：支持 None / Basic256Sha256 等多种安全策略。
- **节点树浏览**：以树形结构浏览服务端地址空间节点。
- **订阅监控**：创建订阅实时监控变量变化。
- **变量读写**：读取或写入指定节点的变量值。
- **原始通信报文查看**：查看底层 OPC UA 通信报文。
- 适用于工业 SCADA / 设备统一数据接入。

## WebSocket

全双工长连接调试：

- 通过 `ws://` 或 `wss://` 地址建立基于 TCP 的双向长连接。
- 连接后向服务端发送消息并实时接收回包，适合调试推送、聊天类服务。

## HTTP

REST / HTTP 端点调试：

- 构造请求（方法、URL、自定义请求头、Body）并发送。
- 查看 HTTP 响应状态码、响应头与响应体，便于验证接口。
- **调试模式可忽略证书**：在测试环境中跳过 TLS 证书校验。

::: tip 没有看到某个协议？
到 **我的 → 设置**，确认对应协议已启用；若仍不出现，请检查应用版本是否为较新版本。
:::
