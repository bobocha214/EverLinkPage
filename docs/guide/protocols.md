# 协议调试

EverLink 内置五种工业 / 物联网常用协议的调试器，统一通过 **设备** 页的卡片管理。各协议在「添加设备」时选择，调试页提供各自的连接与读写界面。

## 支持的协议

| 协议 | 用途 | 典型端口 |
| --- | --- | --- |
| Modbus TCP | 工业 PLC / 仪表的线圈与寄存器读写 | 502 |
| MQTT | 物联网消息的发布（Publish）与订阅（Subscribe） | 1883 / 8883 |
| WebSocket | 与服务端的全双工长连接，收发消息 | 80 / 443 |
| HTTP | REST / HTTP 端点请求调试 | 80 / 443 / 8080 |
| OPC UA | 工业设备地址空间浏览与变量读写 | 4840 |

> 协议在 **我的 → 设置 → 协议配置** 中可单独启用 / 停用。停用后，该协议不会出现在「添加设备」与首页筛选中。

## 通用流程

1. 在 **设备** 页添加设备，选择协议并填写地址。
2. 点击卡片进入调试页，按需填写更详细的连接参数。
3. 点击连接（或在设备卡片上直接连接）。
4. 在调试页进行读写 / 收发，必要时保存为常用操作。
5. 所有连接与操作都会记录到 **历史** 页。

## Modbus TCP

面向工业控制器与仪表的寄存器调试：

- 读取 / 写入 **线圈（Coil）** 与 **保持寄存器（Holding Register）** 等数据区。
- 通过 `主机 IP + 端口（默认 502）+ 从站地址（Unit ID）` 定位设备。
- 适用于 PLC、温湿度变送器、电表等 Modbus 从站。

## MQTT

物联网消息调试：

- 连接到 MQTT Broker（需 `主机 + 端口`，支持用户名 / 密码）。
- **订阅（Subscribe）** 主题以接收消息，**发布（Publish）** 消息到指定主题。
- 常用于传感器上报、设备控制指令下发。

## WebSocket

全双工长连接调试：

- 通过 `ws://` 或 `wss://` 地址建立连接。
- 连接后向服务端发送消息并实时接收回包，适合调试推送、聊天类服务。

## HTTP

REST / HTTP 端点调试：

- 构造请求（方法、URL、Header、Body）并发送。
- 查看响应状态码、响应头与响应体，便于验证接口。

## OPC UA

工业设备地址空间调试：

- 连接到 OPC UA 服务端（默认端口 4840）。
- **浏览（Browse）** 地址空间节点，读取 / 写入变量（Variable）。
- 适用于工业 SCADA / 设备统一数据接入。

::: tip 没有看到某个协议？
到 **我的 → 设置**，确认对应协议已启用；若仍不出现，请检查应用版本是否为较新版本。
:::
