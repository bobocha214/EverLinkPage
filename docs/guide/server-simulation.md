# 服务模拟

EverLink 不仅是协议调试**客户端**，还可以在手机上**运行服务端**，方便你在没有真实设备时联调客户端程序。

入口：**工具 → 服务模拟**，包含以下四个模块：

| 模块 | 说明 |
| --- | --- |
| TCP 服务端 | 监听端口、接受多客户端连接、广播 / 定向发送、透传转发 |
| OPC UA 服务端 | 模拟 OPC UA 服务器（None 安全策略），自定义节点，支持 Read / Write / Browse |
| MQTT Broker | 本地 MQTT 3.1.1 服务器，接受客户端连接、转发消息、Retained、通配符 |
| MQTT 发布模拟 | 连接外部 Broker，按主题模板循环发布模拟设备数据 |

::: tip 后台运行
服务模拟在应用生命周期内**常驻运行**——退出服务模拟页面后，已启动的服务**不会停止**，仍可在后台接受连接 / 转发消息。需要停止时，进入对应页面点击「停止」按钮。
:::

## TCP 服务端

在手机上启动一个轻量 TCP 服务端，接受多个客户端连接，用于联调你自己的 TCP 客户端程序。

### 功能

- **监听端口**：指定端口号启动监听，可选绑定特定网卡或全部接口（`0.0.0.0`）。
- **多客户端**：同时接受多个 TCP 客户端连接，实时显示客户端地址列表。
- **广播发送**：向所有已连接客户端广播数据（文本或 Hex）。
- **定向发送**：向指定客户端单独发送数据。
- **透传转发**：开启后，收到某客户端的数据自动转发给其他客户端（适合做回显 / 透传调试）。
- **收发日志**：以 hex dump 格式记录所有收发数据，标注方向（发送 / 接收）和来源客户端。
- **断开客户端**：可手动断开指定客户端连接。

### 使用场景

- 联调自定义 TCP 客户端程序，无需在电脑上额外启动服务端。
- 模拟设备 TCP 接口，验证客户端的连接、发包、断线重连逻辑。
- 透传模式下做简单的消息中继调试。

## OPC UA 服务端

在手机上模拟一个 OPC UA 服务器，支持客户端连接并执行 Read / Write / Browse 操作。

### 功能

- **安全策略**：SecurityPolicy = None（匿名访问，无需认证）。
- **协议实现**：HEL/ACK、OpenSecureChannel、CreateSession、ActivateSession、Read、Write、Browse、CloseSession、CloseSecureChannel。
- **节点编辑器**：可自定义地址空间——添加 / 删除变量节点，编辑 NodeId、命名空间、显示名、数据类型、当前值。
- **默认节点**：首次进入预置 5 个示例节点（命名空间 2）：

| NodeId | 名称 | 数据类型 | 默认值 |
| --- | --- | --- | --- |
| ns=2;s=1 | Temperature | Double | 25.5 |
| ns=2;s=2 | Pressure | Float | 101.3 |
| ns=2;s=3 | Running | Boolean | true |
| ns=2;s=4 | DeviceName | String | EverLink-Sim |
| ns=2;s=5 | Count | Int32 | 123 |

- **支持的数据类型**：Boolean、SByte、Byte、Int16、UInt16、Int32、UInt32、Int64、UInt64、Float、Double、String。
- **通信报文**：实时显示底层 OPC UA 二进制报文收发记录。
- **客户端列表**：显示当前已连接的客户端地址。

### 使用场景

- 联调 OPC UA 客户端程序，验证 Read / Write / Browse 逻辑。
- 无真实 PLC 时模拟工业设备地址空间。
- 测试 OPC UA 客户端的节点发现与变量读写。

::: warning 限制
当前仅支持 None 安全策略与匿名访问，不支持签名策略（Basic256Sha256 等）和用户名 / 证书认证。订阅（Subscription / MonitoredItem）暂不支持。
:::

## MQTT Broker

在手机上运行一个最小 MQTT 3.1.1 Broker，接受其他 MQTT 客户端连接、订阅、发布消息。

### 功能

- **MQTT 3.1.1 协议**：纯 Dart 内存实现，单进程内完成消息路由。
- **支持报文**：CONNECT/CONNACK、SUBSCRIBE/SUBACK、PUBLISH（QoS 0/1）、PUBACK、UNSUBSCRIBE/UNSUBACK、PINGREQ/PINGRESP、DISCONNECT。
- **通配符订阅**：支持 `+`（单层）和 `#`（多层）通配符主题匹配。
- **Retained 消息**：支持 Retained 消息存储与新订阅者自动投递。
- **消息转发**：发布者发送的消息自动转发给匹配主题的订阅者（不回传给发布者自身）。
- **任意认证**：接受任意用户名 / 密码（不做校验），便于调试。
- **客户端列表**：显示当前已连接的客户端 ID 与地址。
- **报文日志**：实时显示所有 MQTT 报文收发记录（含报文类型、方向、主题、QoS）。

### 使用场景

- 无外部 MQTT Broker 时，在局域网内用手机充当 Broker 联调多个 MQTT 客户端。
- 验证客户端的订阅 / 发布 / 通配符匹配 / Retained 消息逻辑。
- 搭配「MQTT 发布模拟」组成完整的端到端测试链路。

::: warning 限制
QoS 2 仅做简化处理（回 PUBREC 后不再追踪），不支持持久会话（cleanSession=false 的离线消息保留）。适合本地调试，不建议用于生产环境。
:::

## MQTT 发布模拟

连接到一个外部 MQTT Broker，按配置的主题模板、数量、间隔循环发布模拟设备数据。

### 功能

- **连接外部 Broker**：填写主机、端口、用户名 / 密码（可选），连接到任意 MQTT Broker。
- **主题模板**：支持 `{i}` 占位符，发布时自动替换为序号（如 `device/{i}/temperature` → `device/1/temperature`、`device/2/temperature`…）。
- **批量发布**：可配置一次生成多少个主题的消息。
- **定时循环**：按设定间隔（毫秒级）循环发布，持续模拟设备上行数据。
- **QoS 设置**：支持 QoS 0 / 1 / 2。
- **模拟数据类型**：自动随机生成 4 种典型工业数据——温度（20~30°C）、计数（0~99）、湿度 / 压力（0~100）、开关状态（ON/OFF）。
- **发布日志**：实时显示每次发布的主题与值。

### 使用场景

- 模拟批量传感器设备向 Broker 上报数据，测试订阅端的处理能力。
- 验证 MQTT 消息路由规则（通配符订阅 + 多主题发布）。
- 压力测试 Broker 或下游数据处理管道。

## 服务管理

所有服务模拟由 `ServerRegistry` 统一管理，采用**单例模式**：

- **常驻运行**：服务启动后，即使退出服务模拟页面或切换到其他页面，服务**继续在后台运行**。
- **手动停止**：需要停止时，进入对应服务页面点击「停止」按钮。
- **互不干扰**：四个服务可同时运行（注意端口不要冲突）。
- **应用退出释放**：应用完全退出时自动停止所有服务并释放资源。

::: tip 端口冲突
同时运行多个服务时，请确保各服务监听不同端口。例如 TCP 服务端用 8080、MQTT Broker 用 1883、OPC UA 服务端用 4840。
:::
