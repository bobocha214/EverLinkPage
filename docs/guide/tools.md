# 工具箱

「工具」页聚合了 EverLink 的若干独立实用工具，覆盖文件互传、剪贴板、网络诊断与进制计算。

## 快传（局域网传输）

同一 WiFi 下，通过**网页**或**扫码**在手机与电脑 / 手机之间互传文件、文字与图片。

- **频道**：创建或加入频道（可设为私有，需密码、内容加扰），频道卡片上的二维码可分享给他人加入。
- **设备**：自动发现同网段已开启快传的设备，也支持「手动添加设备」（直接填对方 IP）。
- **点对点**：点击已发现设备，仅与它单独收发，不经过频道。
- **网页端**：电脑浏览器打开手机显示的局域网地址（如 `http://192.168.1.23:5321/`）即可收发。
- 收到的文件保存在应用文档目录 `EverLink/Received/`。

::: warning 搜不到设备？
1. 双方连同一 WiFi 且都打开快传页；
2. 点右上放大镜「扫描」主动探测整个网段；
3. 仍不行用菜单「手动添加设备」直接填对方 IP；
4. 部分路由器开启 AP 隔离会导致设备互不可见，需在路由器中关闭。
iOS 首次会请求「本地网络」权限，请允许。
:::

## 剪贴板管理

本地记录本机所有复制内容（含其它 App 复制的内容），可查看、复制、删除。

- 自动记录本应用内复制，并在 EverLink 处于前台时记录其它 App 的复制；
- 点击条目可查看详情并复制，支持单条删除与「清空全部」；
- **数据仅保存在本机**，不上传任何服务器。

> 平台限制：Android 10+ / iOS 14+ 禁止后台读取剪贴板，因此其它 App 的复制仅在 EverLink 前台时才会被捕获。

## 网络诊断（Ping）

对目标主机执行真实的 ICMP Echo 探测（调用系统 `ping`），查看时延与丢包率。

- 可设置次数、间隔、超时；
- 实时展示每次回显的时延，结束后汇总丢包率与 min / avg / max；
- 自动记录最近 Ping 过的主机，便于重测，历史可在弹窗中查看 / 删除 / 清空。

## 网络调试

五个标签页的通用网络工具集：

| 标签页 | 功能 |
| --- | --- |
| TCP 客户端 | 建立原始 TCP 连接，发送文本 / Hex，以 hex dump 展示收发日志 |
| 端口扫描 | 对目标 IP 并发探测端口（支持 `a-b` 区间），列出开放端口及服务 |
| 目标探测 | 对目标多次 TCP 连通性探测并统计 RTT（TCP Ping） |
| 局域网扫描 | 扫描某网段内开放指定端口的主机 IP（主机发现，非 Modbus 站号） |
| IP 计算 | IP / 子网掩码（或 /CIDR）换算网络地址、广播地址、可用主机范围 |

::: info 关于 Traceroute
当前平台不支持逐跳 Traceroute（无 `ipTtl`、无法创建原始 ICMP 套接字），「目标探测」退化为多次 TCP 连通性探测 + RTT 统计，用于判断设备可达性与时延，无法列出中间路由 IP，结果仅供参考。
:::

## 进制工具

- 二 / 八 / 十 / 十六进制互转；
- 补码计算、字节视图；
- 文本 ⇄ Hex 互转；
- CRC16 校验计算。

适合调试协议报文、校验字段时快速换算。
