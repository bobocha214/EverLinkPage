# 快速开始

本页带你用最短路径跑通 EverLink 的核心流程：**添加设备 → 连接 → 调试**。

## 1. 添加设备

在 **设备** 页右下角点击 **添加设备**，按步骤操作：

1. 选择协议类型（如 Modbus TCP）。
2. 填写设备名称（便于在列表中识别）。
3. 填写连接参数（如 Modbus TCP 的 `主机 IP` 与 `端口 502`）。
4. 保存后自动进入该设备的调试页。

> 地址也可以先留空，保存后到调试页再填，但连接前必须填写有效地址。

## 2. 连接与断开

在 **设备** 页的卡片上：

- 点击右侧的 **连接 / 断开** 图标，即可建立或断开连接。
- 连接成功与否会写入「历史」页，方便回溯。

卡片顶部会显示当前状态：

| 状态 | 含义 |
| --- | --- |
| 在线 | 已成功连接 |
| 连接中 | 正在建立连接 |
| 离线 | 未连接 |
| 异常 | 连接出错 |

## 3. 进入调试

点击卡片主体或 **调试** 按钮，进入对应协议的调试界面（详见 [协议调试](./protocols)）。

## 4. 筛选与查找

当设备较多时，点击右上角 **筛选** 图标，可：

- 按名称搜索
- 按协议类型筛选
- 按连接状态（在线 / 离线 / 异常）筛选
- 按设备名下拉筛选

筛选条件生效时，筛选按钮上会出现小红点提示。

## 5. 管理设备

- **重命名**：长按卡片上的编辑图标，修改设备名称。
- **删除**：点击卡片上的删除图标，确认后移除（不可撤销）。
