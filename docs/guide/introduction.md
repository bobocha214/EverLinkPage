# 简介

**EverLink** 是一款面向现场工控 / 物联网调试工程师的**多协议设备调试与网络诊断工具**，基于 Flutter 跨平台开发。它把现场最常用的多种工业通信协议、网络诊断能力和日常小工具集成到一个 App 中，帮助工程师在手机 / 平板上完成设备联调、报文抓看、网络排查与文件快传，无需随身携带笔记本。

## 它能做什么

| 模块 | 说明 |
| --- | --- |
| 多协议调试 | Modbus TCP、MQTT、OPC UA、WebSocket、HTTP 五种协议的连接与读写 |
| 服务模拟 | 在手机上运行 TCP 服务端、OPC UA 服务端（含节点编辑器）、MQTT Broker、MQTT 发布模拟，无需电脑即可联调客户端 |
| 设备管理 | 首页卡片化展示设备，统计在线 / 连接中 / 离线 / 异常，支持搜索与按协议 / 状态筛选、重命名与删除 |
| 历史记录 | 集中展示连接与操作流水（时间、协议、设备、操作、成功 / 失败、错误信息），便于事后复盘 |
| 局域网快传 | 同一 WiFi 下通过网页 / 扫码互传文件、文字、图片，支持公开频道与加密房间 |
| 网络诊断 | 真实 ICMP Ping（时延、丢包），以及 TCP 客户端、端口扫描（含工控常用端口预置）、目标探测、局域网扫描、IP 子网计算 |
| 剪贴板管理 | 本地记录复制内容（含其它 App），可查看、复制、清理 |
| 进制工具 | 二 / 八 / 十 / 十六进制互转、补码、字节视图、文本 ⇄ Hex、CRC16-Modbus 校验计算 |
| 应用内更新 | 从 GitHub / Gitee Releases 检查更新，一键下载安装 |

## 界面概览

App 底部为四个主页面：

- **设备**：所有已保存设备的列表，可一键连接 / 断开、进入调试、重命名、删除。
- **历史**：连接与操作流水记录（时间、协议、设备、操作、成功 / 失败、错误信息）。
- **工具**：快传、剪贴板管理、网络诊断、网络调试、进制工具、**服务模拟**（TCP / OPC UA / MQTT Broker / MQTT 发布模拟）的集合入口。
- **我的**：设置（协议开关、检查更新）、主题切换、关于。

## 技术架构

项目采用分层设计，降低各协议模块之间的耦合：

```
协议层 (Modbus / MQTT / OPC UA / HTTP / TCP·UDP / WebSocket)
   ↓
会话 / 连接管理层 (ConnectionManager · SessionManager)
   ↓
采集与解析层 (数据点位、寄存器解析、JSON 处理)
   ↓
可视化 / 存储层 (趋势曲线、历史记录、本地持久化)
   ↓
工具层 / 配置层 (快传、网络诊断、进制工具、连接模板)
```

- **配置驱动**：所有协议的连接参数统一抽象为「连接配置模型」，由 `ProtocolRegistry` 注册并复用，新增协议只需在枚举 `ProtocolType` 中追加一项并实现 `DeviceProtocol`。
- **异步优先**：阻塞式协议操作（Socket、TLS 握手、定时轮询）跑在独立 isolate / 后台线程，UI 仅消费流式数据，避免 ANR。
- **本地优先**：会话、历史、剪贴板历史、设置等均持久化于本地（SharedPreferences / 文件系统），无需后端服务。

## 适用人群

- 工业自动化 / 设备维护工程师
- 物联网开发、嵌入式调试人员
- 需要在移动端快速排查设备通信与网络问题的技术人员

::: tip 提示
EverLink 仅供设备调试与学习使用，请勿用于未授权设备的接入与数据获取。
:::
