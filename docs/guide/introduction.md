# 简介

**EverLink** 是一款面向工业现场与物联网场景的 Android 设备协议调试工具。它把常用的工业通信协议调试能力与局域网协作工具整合到一个 App 中，方便工程师在现场快速连接设备、读写数据、排查网络问题。

## 它能做什么

| 模块 | 说明 |
| --- | --- |
| 协议调试 | Modbus TCP、MQTT、WebSocket、HTTP、OPC UA 五种协议的连接与读写 |
| 设备管理 | 首页卡片化展示设备，统计在线 / 连接中 / 离线 / 异常，支持搜索与筛选 |
| 局域网快传 | 同一 WiFi 下通过网页或扫码互传文件 / 文字 / 图片，支持频道与私有房间 |
| 网络诊断 | 真实 ICMP Ping（时延、丢包），以及 TCP 客户端、端口扫描、目标探测、子网计算 |
| 剪贴板管理 | 本地记录复制内容（含其它 App），可查看、复制、清理 |
| 应用内更新 | 从 GitHub / Gitee Releases 检查更新，一键下载安装 |

## 界面概览

App 底部为四个主页面：

- **设备**：所有已保存设备的列表，可连接 / 断开、进入调试、重命名、删除。
- **历史**：连接记录、Ping 记录等历史日志。
- **工具**：快传、剪贴板管理、网络诊断、网络调试、进制工具的集合入口。
- **我的**：设置（协议开关、检查更新）、主题、关于。

## 适用人群

- 工业自动化 / 设备维护工程师
- 物联网开发、嵌入式调试人员
- 需要在移动端快速排查设备通信与网络问题的技术人员

::: tip 提示
EverLink 仅供设备调试与学习使用，请勿用于未授权设备的接入与数据获取。
:::
