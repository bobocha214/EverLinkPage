# 常见问题（FAQ）

## 安装与更新

### 安装 APK 时提示「禁止安装未知应用」？
Android 8+ 的权限保护。进入系统设置，找到 EverLink（或在安装弹窗中点「设置」），允许「安装未知应用」，再返回继续安装即可。

### 应用内检查更新失败 / 一直超时？
- 确认已正确填写仓库坐标 `owner/repo`（如 `zhiyu_214/ever-link` 或 `bobocha214/everlink`）；
- 若使用 **Gitee**，未登录的公开 API 有限速，失败时可稍后重试或改用 **GitHub**；
- 检查设备是否能正常联网访问对应平台。

### 下载更新后没有自动安装？
下载完成后系统应弹出安装器。若未弹出，请到系统「文件管理 / 下载」中找到 `app-*-release.apk` 手动安装。部分系统需要手动点击通知。

## 协议调试

### 连接设备提示失败 / 超时？
- 确认 `主机 IP` 与 `端口` 正确，且设备在线、网络可达；
- 确认手机与目标设备处于同一网络（或被防火墙放行）；
- 用「工具 → 网络调试 → 端口扫描 / 目标探测」验证端口是否开放。

### 为什么「添加设备」里看不到某个协议？
到 **我的 → 设置 → 协议配置**，确认该协议已启用。

## 快传

### 同一 WiFi 但互相搜不到？
见 [工具箱 → 快传](./tools#快传局域网传输) 的排查清单：确认同 WiFi、用扫描、手动添加 IP，并关闭路由器 AP 隔离。

### 电脑怎么接收手机传的文件？
在电脑浏览器打开手机快传页显示的局域网地址（如 `http://192.168.1.23:5321/`），即可与手机互传。

## 剪贴板

### 为什么有时没有记录到其它 App 的复制？
Android 10+ / iOS 14+ 禁止后台读取剪贴板，EverLink 只能在前台时捕获其它 App 的复制。本应用内复制则始终会被记录。

## 其它

### 我的数据会上传吗？
不会。剪贴板历史、连接历史、Ping 历史等均仅保存在本机，EverLink 不会上传任何个人隐私数据。

### 支持 iOS 吗？
当前分发形态为 Android APK。是否提供 iOS 版本以实际发布渠道为准。
