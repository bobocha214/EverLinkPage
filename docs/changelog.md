# 更新日志

本页记录 EverLink 的版本发布历史。每个版本对应一个 GitHub / Gitee Release（Tag 形如 `v1.0.0`）。

## v1.0.0

> 首发版本

- **协议调试**：内置 Modbus TCP、MQTT、WebSocket、HTTP、OPC UA 五种协议调试器
- **设备管理**：首页卡片化展示设备，统计在线 / 连接中 / 离线 / 异常，支持搜索与筛选、重命名、删除
- **局域网快传**：同一 WiFi 下通过网页 / 扫码互传文件、文字、图片，支持频道与私有加密房间
- **网络诊断**：真实 ICMP Ping 测时延与丢包，含历史记录
- **网络调试**：TCP 客户端、端口扫描、目标探测、局域网扫描、IP 子网计算
- **剪贴板管理**：本地记录复制内容（含其它 App），可查看 / 复制 / 清理
- **进制工具**：二/八/十/十六进制互转、补码、字节视图、文本⇄Hex、CRC16
- **设置与主题**：协议启用 / 停用、teal 主色、浅色 / 深色 / 跟随系统主题
- **应用内更新**：从 GitHub / Gitee Releases 检查更新，一键下载安装

---

::: tip 提交你的版本
版本号以 `pubspec.yaml` 中的 `version` 为准。发布时创建带 `v` 前缀的 Release 并上传 `EverLink-<版本>.apk`，应用内即可检测到更新。
:::
