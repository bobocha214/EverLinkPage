# 更新日志

本页记录 EverLink 的版本发布历史。每个版本对应一个 GitHub / Gitee Release（Tag 形如 `1.0.0`）。

## v1.0.0

> 首发版本

- **协议调试**：内置 Modbus TCP、MQTT、OPC UA、WebSocket、HTTP 五种协议调试器
  - Modbus TCP：寄存器 / 线圈读写、数据类型解析（INT16/UINT16/INT32/UINT32/FLOAT32/BCD）、字节序 / 字交换切换、定时轮询、原始 Hex 报文查看、日志导出
  - MQTT：3.1.1 / 5.0、TLS/SSL、用户名密码与证书认证、多主题订阅（`#`/`+` 通配符）、JSON 格式化高亮、消息历史与发布模板
  - OPC UA：Endpoint 发现、安全策略协商（None/Basic256Sha256 等）、节点树浏览、订阅监控、变量读写、原始通信报文查看
  - WebSocket：基于 TCP 的双向长连接调试
  - HTTP：自定义请求头 / GET·POST、调试模式可忽略证书
- **服务模拟**：在手机上运行服务端，联调客户端程序
  - TCP 服务端：监听端口、多客户端、广播 / 定向发送、透传转发
  - OPC UA 服务端：None 安全策略、自定义节点编辑器（增删改 NodeId / 类型 / 值）、Read / Write / Browse、预置 5 个示例节点
  - MQTT Broker：MQTT 3.1.1 内存实现、通配符订阅、Retained 消息、QoS 0/1、多客户端转发
  - MQTT 发布模拟：连接外部 Broker、主题模板 `{i}` 占位、定时循环发布模拟数据（温度 / 计数 / 湿度 / 开关）
- **设备管理**：首页卡片化展示设备，统计在线 / 连接中 / 离线 / 异常，支持搜索与筛选、重命名、删除
- **历史记录**：连接与操作流水（时间、协议、设备、操作、成功 / 失败、错误信息）
- **局域网快传**：同一 WiFi 下通过网页 / 扫码互传文件、文字、图片，支持频道与私有加密房间
- **网络诊断**：真实 ICMP Ping 测时延与丢包，含历史记录
- **网络调试**：TCP 客户端、端口扫描（含工控常用端口预置）、目标探测、局域网扫描、IP 子网计算
- **剪贴板管理**：本地记录复制内容（含其它 App），可查看 / 复制 / 清理
- **进制工具**：二 / 八 / 十 / 十六进制互转、补码、字节视图、文本 ⇄ Hex、CRC16-Modbus
- **设置与主题**：协议启用 / 停用、teal 主色、浅色 / 深色 / 跟随系统主题
- **应用内更新**：从 GitHub / Gitee Releases 检查更新，一键下载安装

---

::: tip 发布新版本
版本号以 `pubspec.yaml` 中的 `version` 为准。发布时创建 Release（Tag 填版本号如 `1.0.0`）并上传 `app-*-release.apk`，应用内即可检测到更新。
:::
